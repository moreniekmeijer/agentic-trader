# Phase 01, Plan 01: Worker Resilience & Idempotency

**Goal**: Implement the "Always-on" foundation by adding database persistence for worker state and unique idempotency keys for all trades.

## Context
- **Requirement**: RELI-01 (Continuous Worker), RELI-02 (Idempotency).
- **Decision**: Hybrid persistence (Watchlist/Heartbeat in DB).
- **Decision**: `decision.id` -> `client_order_id`.

## Proposed Changes

### 1. Database Layer

#### [MODIFY] [models.py](file:///Users/macbook/Documents/VSCode/agentic-trader/agentic_trader/database/models.py)
- Add `WorkerHeartbeat` model to track `last_seen` and `active_symbols`.

#### [MODIFY] [repository.py](file:///Users/macbook/Documents/VSCode/agentic-trader/agentic_trader/database/repository.py)
- Add `SystemRepository` with `update_heartbeat(symbols: list[str])` and `get_last_heartbeat()`.

### 2. Alpaca Controller

#### [MODIFY] [alpaca_controller.py](file:///Users/macbook/Documents/VSCode/agentic-trader/agentic_trader/controller/alpaca_controller.py)
- Update `place_market_order`, `buy`, and `sell` to accept an optional `client_order_id: str`.

### 3. Execution Engine

#### [MODIFY] [engine.py](file:///Users/macbook/Documents/VSCode/agentic-trader/agentic_trader/decision/engine.py)
- In `execute_decision`, pass the `decision.id` (as a string) to `_execute_trade`.
- Update `_execute_trade` to pass the `client_order_id` down to the `alpaca` controller.

### 4. Worker State & Orchestration

#### [MODIFY] [scan_state.py](file:///Users/macbook/Documents/VSCode/agentic-trader/agentic_trader/worker/scan_state.py)
- Add `load_from_db(session)` and `persist_to_db(session)` methods to `WorkerState`.
- `persist_to_db` will only save the symbol list (Hybrid approach).

#### [MODIFY] [worker.py](file:///Users/macbook/Documents/VSCode/agentic-trader/agentic_trader/worker/worker.py)
- Update `if __name__ == "__main__":` to call `state.load_from_db()` on startup.
- Update `scan_job` to call `state.persist_to_db()` after updating symbols.
- Update `trade_job` to call `state.persist_to_db()` (for heartbeat update).
