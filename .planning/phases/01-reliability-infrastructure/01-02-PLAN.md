# Phase 01, Plan 02: Robust Synchronization

**Goal**: Perfect the synchronization between Alpaca and the local database to ensure P&L accuracy and position state consistency (RELI-03).

## Context
- **Requirement**: RELI-03 (PnL/Position Sync).
- **Decision**: 1-5 minute polling interval.
- **Issue**: Current `PnlSyncJob` assumes activity objects have attributes, but they are returned as dicts from the REST API.

## Proposed Changes

### 1. P&L Sync Fixes

#### [MODIFY] [pnl_sync.py](file:///Users/macbook/Documents/VSCode/agentic-trader/agentic_trader/worker/pnl_sync.py)
- Update `_index_by_order` to handle dictionary access (e.g., `activity.get("order_id")`) instead of `getattr`.
- Ensure `realized_pl` is correctly parsed from the Alpaca activity JSON.

### 2. Position Reconciliation

#### [NEW] [reconciliation.py](file:///Users/macbook/Documents/VSCode/agentic-trader/agentic_trader/worker/reconciliation.py)
- Implement a `ReconciliationJob` that compares Alpaca `get_all_positions()` with our `Trade` table.
- **Case 1**: Alpaca has no position for Symbol X, but our DB has an open `Trade`. 
    - Action: Mark the trade as closed (emergency reconciliation).
    - Rationale: This handles cases where a FILL activity was missed or an order was canceled/closed manually.

### 3. Orchestration

#### [MODIFY] [worker.py](file:///Users/macbook/Documents/VSCode/agentic-trader/agentic_trader/worker/worker.py)
- Set `PNL_SYNC_INTERVAL = 5` (minutes).
- Integrate `ReconciliationJob` into the scheduler (e.g., every 10 minutes).

## Verification Plan

### Automated Tests
- Unit tests for `_index_by_order` with sample Alpaca JSON.
- Mock reconciliation test: Simulate Alpaca having 0 shares and DB having 10 shares, verify trade is closed.

### Manual Verification
1. Open a position in Alpaca Paper manually.
2. Manually insert a corresponding "open" trade in the DB.
3. Close the position in Alpaca Paper manually.
4. Run the sync/reconciliation job.
5. Verify the DB trade is marked as closed and P&L is calculated (if possible) or at least the state is corrected.
